# 夸克网盘 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有百度流程上增加夸克：Cookie 绑定、扫码登录、文件管理、转存、分享、下载、分享同步和数据统计。迅雷仍是「暂未开放」。

**Architecture:** 新增 `QuarkAdapter`，方法名与 `BaiduAdapter` 对齐。转存、分享、同步、下载仍走现有任务和页面，按账号的 `provider` 选择适配器。夸克目录用 fid：根目录 path 是 `/`，子目录 path 是 `/{fid}`。免费用户百度、夸克各 1 个有效账号，付费各 5 个。每日 100 条转存额度两个网盘共用。Worker 仍是现在的单进程，整单结束后一次提交。

**Tech Stack:** Python 3.12、FastAPI、SQLAlchemy 2、httpx、pytest。前端 Vite + React + TypeScript + Tailwind。测试数据库仍是 SQLite。不请求真实夸克。

**规格：** `docs/superpowers/specs/2026-10-09-quark-design.md`

**不要改：** Worker 的领取、重试和整单提交。迅雷。跨网盘转存。不要编造夸克没有返回的浏览量、下载量、转存量。

`backend/app/pans/quark.py`：

```python
import httpx

from app.pans.errors import LoginRejected

BASE = "https://drive-pc.quark.cn/1/clouddrive"
PARAMS = {"pr": "ucpro", "fr": "pc"}
USER_AGENT = (
    "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
    "(KHTML, like Gecko) Chrome/122.0.0.0 Safari/537.36"
)


class QuarkAdapter:
    def __init__(self, client: httpx.Client) -> None:
        self.client = client

    def _headers(self, cookie: str) -> dict[str, str]:
        return {"Cookie": cookie, "User-Agent": USER_AGENT}

    def verify_login(self, cookie: str) -> str:
        try:
            response = self.client.get(
                f"{BASE}/member",
                params=PARAMS,
                headers=self._headers(cookie),
                timeout=10,
            )
            payload = response.json()
        except Exception as exc:
            raise LoginRejected() from exc
        data = payload.get("data") if isinstance(payload, dict) else None
        nickname = data.get("nickname") if isinstance(data, dict) else None
        if payload.get("status") != 200 or not isinstance(nickname, str) or not nickname.strip():
            raise LoginRejected()
        return nickname.strip()
```

### Task 8: 夸克扫码登录

**Files:**
- Create: `backend/app/pans/quark_login.py`
- Modify: `backend/app/api/routes/accounts.py`
- Modify: `backend/app/schemas/account.py`（若登录响应已经是通用结构则只复用）
- Test: `backend/tests/test_quark_login.py`

扫码是另一套登录，不复用百度的 sign。会话仓库继续用现有内存登录表，`sign` 字段存夸克的 token。

接口（测试锁定这份约定）：

1. `GET https://uop.quark.cn/cas/ajax/getTokenForQrcodeLogin`，参数 `client_id=532&v=1.2`。响应 `{"status":2000000,"data":{"token":"qr-token"}}`。
2. 二维码图片：`GET https://su.quark.cn/4_eMHBJ`，参数 `token`、`client_id=532`。响应是 PNG 字节。
3. `GET https://uop.quark.cn/cas/ajax/getServiceTicketByQrcodeToken`，参数 `client_id=532&v=1.2&token=qr-token`。
   - 未扫：`data.status` 为 0 或缺失，返回等待。
   - 已扫未确认：`data.status == 1`。
   - 过期：HTTP 非 200 或 `status` 表示过期。
   - 已确认：响应含 `service_ticket`。
4. `GET https://uop.quark.cn/cas/ajax/loginWithServiceTicket`，参数 `st`。响应 `Set-Cookie` 里收集 cookie。再用 `QuarkAdapter.verify_login` 取昵称。

路由与百度平行：

- `POST /api/accounts/quark/login`
- `GET /api/accounts/quark/login/{id}/qrcode`
- `GET /api/accounts/quark/login/{id}`
- `POST /api/accounts/quark/login/{id}/confirm`
- `DELETE /api/accounts/quark/login/{id}`

确认时检查夸克名额，写入 `provider="quark"`。重新登录时 `account_id` 必须属于夸克账号。
