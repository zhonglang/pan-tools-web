# 资源库单条新增设计

日期：2026-10-15

## 目标

资源库支持用户手工新增单条资源，不依赖表格导入。

## 交互

- 页头增加「新增资源」按钮（与「上传表格」并列）。
- 弹窗字段：编号、剧名、夸克链接、百度链接、迅雷链接。
- 编号、剧名必填；三家链接均可空，但至少填一条。
- 编号须为纯数字（1–16 位），与现有 `prefix` 规则一致。
- 编号已存在则返回冲突错误，不覆盖；改链接继续用「编辑」。

## 接口

`POST /api/library`

请求体：

```json
{
  "prefix": "001",
  "name": "剧名",
  "quark_url": "",
  "baidu_url": "https://pan.baidu.com/s/xxx",
  "xunlei_url": ""
}
```

- 非空链接须能识别为对应网盘；否则 422。
- 成功返回 `LibraryItemOut`。
- 同用户同编号已存在 → 422「编号已存在」。

## 非目标

- 不自动合并导入式覆盖。
- 不改检查链接 / 导入表格逻辑。
