# 批量转存「复制到」设计

日期：2026-10-13

在批量转存页操作列增加「复制到」，把某个文件或文件夹复制到同一账号下的一个或多个同级目录。百度、夸克、迅雷都支持。所有登录用户可用。

## 交互

操作列在「分享」旁显示「复制到」。点击后弹出目录选择框：

- 可浏览当前网盘目录（面包屑 + 进入子目录），列表只显示文件夹。
- 进入某个父目录后，勾选它下面的一个或多个子文件夹作为目标。
- 已有勾选时，不能再进入其他目录；清空勾选后才能继续浏览。
- 禁止把源文件夹复制到自身或其子孙目录。源文件所在目录可以作为目标。
- 底部显示「已选 N 个」。N ≥ 1 且未执行时可确认。执行中按钮为「正在复制」，并禁用关闭。

## 接口

`POST /api/accounts/{id}/files/copy`

请求：

```json
{
  "path": "/源路径",
  "fs_id": 123,
  "name": "原名称",
  "targets": ["/父/A", "/父/B"]
}
```

`fs_id` 可空。`targets` 1–50 个，必须同父目录。

响应：

```json
{
  "succeeded": 2,
  "failed": 0,
  "results": [
    { "path": "/父/A", "name": "原名称", "ok": true, "error": null },
    { "path": "/父/B", "name": "原名称(1)", "ok": true, "error": null }
  ]
}
```

后端依次复制。某个目标失败不中断其余。登录失效时，后续目标全部记失败。不做后台任务。

## 重名

目标目录已有同名项时，自动改名后复制：`名称` → `名称(1)` → `名称(2)`…  
文件保留扩展名（如 `a.txt` → `a(1).txt`）。文件夹整名加后缀。

## 网盘

- 百度：`filemanager` 的 `copy`。
- 夸克、迅雷：补对应复制接口，走现有适配器。

## 反馈

- 全部成功：关闭弹框，顶部绿色 toast「已复制到 N 个目录」。
- 部分失败：弹框保留，列出失败目标与原因；成功数用 toast 提示。
- 全部失败：弹框保留并显示错误。
- 不自动刷新当前目录列表。

## 测试

HTTP 使用假响应，不请求真实网盘。覆盖：

- 三网盘成功复制
- 同名自动改名
- 目标必须同级
- 禁止复制到自身或子孙
- 前端勾选同级与确认流程
